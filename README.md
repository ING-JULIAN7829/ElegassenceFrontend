##Caracteristicas
-El diseño de esta pagina esta enfocado en transmitir lujo y calidad para los productos de perfumeria 
-El pequeño ecommerce cuenta con filtros avanzados por caracteristicas y busqueda de productos
-Los productos se pueden agregar a un carrito que recolecta informacion de contacto del cliente
-Se cuenta con acceso a whatsapp directo
-Los pedidos se generan directamente por whatsapp
